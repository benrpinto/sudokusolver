# Sudoku Solver
Programs to solve Sudokus using the backtracking algorithm (a form of DFS). Input is via a text file. User inputs the filepath of the text file. Each folder is a standalone program that solves the sudoku in roughly the same way.

Notes:
* In the pySolver there are 2 solvers, main.py and streamlit.py. 
  * main.py takes in a filename and solves the contents of the file. 
  * streamlit.py starts a streamlit app, allowing the user to input the sudoku through a UI
